## Tutorial Summary (Week 1–10)

- **Week 1 – Getting Started with Java:** Setting up the JDK and VS Code, and learning how to actually compile and run a Java program from the terminal (`javac` to compile, then `java` to run the class). Covered basic syntax, variables, data types, and simple console input/output.
- **Week 2 – Control Flow & Methods:** if/else statements, loops (for, while), arrays, and writing simple methods with parameters and return values.
- **Week 3–4 – Classes, Objects & Inheritance:** Building classes with constructors and instance variables, then extending them into subclasses. This is where the `Person`, `Student`, and `Lecturer` classes came in, with each subclass overriding the `introduce()` method to print something different.
- **Week 5 – Encapsulation:** Access modifiers (private/public/protected), getters and setters, and why you'd bother hiding your fields instead of just making everything public.
- **Week 6 – Polymorphism:** Method overloading vs overriding, and how Java decides which version of a method actually runs at runtime.
- **Week 7 – Abstract Classes & Interfaces:** When to use an abstract class vs an interface, and implementing multiple interfaces in one class.
- **Week 8–9 – Exception Handling:** try/catch/finally blocks, throwing custom exceptions, and handling things like invalid input without the whole program crashing.
- **Week 10 – Wrap-up / Mini Project:** Putting most of the earlier concepts together in one small program to review the semester's material.

## How to Run the Projects

1. Clone the repository:
   ```
   git clone https://github.com/Am1neK/KISRANE-AMINE_202505010489_java-programming.git
   ```
2. Open the folder for the week you want to check (e.g. `week_3-4`).
3. Compile the `.java` file:
   ```
   javac FileName.java
   ```
4. Run it:
   ```
   java FileName
   ```
